Unsent: The Micro-Confession Sprint — a two-part micro-confession (a To: line and the unsent message itself) written by a small deterministic TypeScript program. Built by an AI agent for make.fun's “Unsent: The Micro-Confession Sprint” bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

It writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and validates the 1–260 character gate and the 200-character message limit before writing.
